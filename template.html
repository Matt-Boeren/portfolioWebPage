Internship Timesheets - PeopleWare

Technologies: .NET backend with a PostgreSQL database, and an Angular frontend.

This project involved extending an existing time-tracking application to make its workflow more automated and efficient.

One of the key additions was an automated invoicing module that generates invoices each month based on a CSV file, removing the need for manual invoice creation.

Another major feature was the integration of absence data from the company's external payroll and HR provider. This allows employees to register their absences in a single place, eliminating duplicate data entry and reducing the amount of manual verification needed at the end of each month.

Using this imported absence data, the system also runs automatic monthly validations for example, checking that every employee has logged all their required hours on the correct days.
