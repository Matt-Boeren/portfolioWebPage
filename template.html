Record collection app

The record collection app is an application that can keep track of someones vinyl record collection. If a user adds a record to there collection they can give the album a rating, some tags like the RPM of the record, a description and an image.

Now users can only track there own collection. The application state now is the base to make a platform to share your record collection to friends on the platform.

The web version of the application and the backend are written in Laravel.

Later I rewrote the Laravel application to have API endpoints that are useable in a mobile application written in React native.
